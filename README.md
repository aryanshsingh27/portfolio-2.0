# Aryansh Singh – Designer Portfolio

A personal portfolio website showcasing design, development, skills, and selected work.

## Project structure

- `index.html` – page structure and content
- `css/style.css` – core visual styles
- `css/responsive.css` – responsive and media-query styles
- `css/animations.css` – keyframe animation definitions
- `js/main.js` – interactive behavior and intro sequence
- `assets/images/` – embedded raster images extracted from the original HTML
- `assets/icons/` – embedded SVG image assets

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension. The site uses Google Fonts over the internet; all extracted image assets are local.

## Notes

The original layout, text, inline SVG artwork, and JavaScript behavior have been retained while moving CSS, JavaScript, and embedded image data into separate files.
